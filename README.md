# English Daily — английский и узбекский с нуля

Приложение для Samsung (Android) с выбором языка:

- 🇬🇧 **Английский** — 365 дней, от нуля до уровня B2 (комфортный разговор на общие темы).
- 🇺🇿 **Узбекский** — 183 дня, от нуля до свободного бытового разговора; латиница с подсказкой чтения русскими буквами.

- Каждая неделя: 5 уроков (слова, правило, тренировка, говорение), повторение и разговорный день.
- Озвучка слов и проверка произношения через микрофон.
- Ежедневное напоминание в выбранное время (по умолчанию 20:00).
- Семейный режим: несколько профилей на одном телефоне, каждый выбирает свой язык, прогресс по каждому языку отдельный.
- Общий английский без привязки к профессии: быт, путешествия, общение, мнения, новости.
- Числа можно произносить как угодно: распознанные «10», «7:30», «2025», «21st» засчитываются как слова.

## Устройство проекта

- `web/` — интерфейс и уроки: английский — `web/course/m01.js` … `m12.js`, узбекский — `web/course/uz/u01.js` … `u06.js` (по месяцам).
- `app/` — Android-оболочка: озвучка, распознавание речи, уведомления.
- `.github/workflows/build.yml` — автоматическая сборка APK при каждом изменении.
