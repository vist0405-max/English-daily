# English Daily — английский с нуля за год

Приложение для Samsung (Android): 365 дней, от нуля до уровня B1.

- Каждая неделя: 5 уроков (слова, правило, тренировка, говорение), повторение и разговорный день.
- Озвучка слов и проверка произношения через микрофон.
- Ежедневное напоминание в выбранное время (по умолчанию 20:00).

## Скачать

**[EnglishDaily.apk — последняя версия](https://github.com/vist0405-max/english-daily/releases/latest/download/EnglishDaily.apk)**

Откройте ссылку на телефоне, скачайте файл и установите. Обновления ставятся поверх, прогресс сохраняется.

## Устройство проекта

- `web/` — интерфейс и уроки (`web/course/m01.js` … `m12.js` — по месяцам).
- `app/` — Android-оболочка: озвучка, распознавание речи, уведомления.
- `.github/workflows/build.yml` — автоматическая сборка APK при каждом изменении.
